# Changelog

## 1.3.0

### Changed

- Ported to Minecraft 26.3.
- Replaced Cut Through with CleanCut, Cubes Without Borders with Borderless Fullscreen, and Zoomify with Ok Zoomer.
- Updated Complementary Unbound to r5.9.3.
- The CurseForge edition omits Borderless Fullscreen because it does not have a Minecraft 26.3 file there.
- The CurseForge edition omits Sounds because its 26.3 dependency chain is not available there.

### Removed

- Removed Sit because Minecraft 26.3 now has cushions.
- Removed Bobby and Particle Effects.

## 1.2.0

- Bundled Complementary Unbound as the pack's only shader.
- The CurseForge edition does not include Presence Footsteps because no Minecraft 26.2 file is available there.
